SparkBooks: Auditing AI Pipelines in Financial Workflows

Role

Founder & Systems Architect

Company

UltimaSpark Agency[cite: 1]

Timeline

2026 – Present[cite: 1]

Core Models

DeepSeek V4 Pro, Whisper[cite: 1]

The Challenge

Small business accounting requires high data accuracy. When processing unstructured inputs—such as voice recordings and informal text messages sent over WhatsApp—traditional AI implementations often face subtle hallucinations, transcription errors, and irregular JSON serialization[cite: 1].

A misheard dollar amount or a mismatched expense category can compromise an entire general ledger. The objective was to build an automated ingestion pipeline that incorporates strict evaluation checks before financial data is written to the database or confirmed back to the user[cite: 1].

The Multimodal QA Architecture

The pipeline handles messages using a multi-step evaluation workflow rather than passing raw audio straight to database queries[cite: 1]:

  • Voice Transcription (OpenAI Whisper): Voice memos submitted via WhatsApp are transcribed into raw text, with confidence scoring applied to flag indistinct audio[cite: 1].
  • Structured Parsing (DeepSeek V4 Pro): The transcribed string is evaluated by DeepSeek V4 Pro using prompt constraints that enforce rigid JSON schemas (identifying date, vendor, total amount, currency, and tax)[cite: 1].
  • Pre-Confirmation Auditing: The model output undergoes validation for hallucinations, impossible date formats, or numerical anomalies before prompting the user for approval[cite: 1].

Preventing Silent Database Failures

Standard AI outputs often miss edge cases in multi-tenant systems. SparkBooks utilizes Supabase Row-Level Security (RLS) policies to ensure that even if an AI prompt is manipulated or corrupted, database transactions remain strictly isolated to the authenticated business tenant[cite: 1].

Technologies Deployed

The system was engineered using a full-stack JavaScript/TypeScript stack integrated with multimodal AI APIs[cite: 1]:

DeepSeek V4 Pro OpenAI Whisper WhatsApp Business API Next.js TypeScript Supabase (PostgreSQL + RLS) Prompt Engineering

Results & Key Takeaways

By treating output evaluation as an engineering discipline, SparkBooks eliminated silent ledger errors and established a dependable bookkeeping interface[cite: 1]:

  • Eliminated hallucinated expense amounts through pre-confirmation data validation[cite: 1].
  • Applied evaluation feedback loops that shaped curriculum standards for 100+ academy students working on LLM integrations[cite: 1].
  • Demonstrated that voice-driven AI bookkeeping can meet production reliability standards when backed by manual and automated QA[cite: 1].
